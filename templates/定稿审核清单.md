# 发明专利定稿审核清单（人工确认）

## 公开、真实与权属
- [ ] 首次公开形式及时间经确认
- [ ] 发明人与实际技术贡献匹配、权属清晰
- [ ] 所有量化表述有真实数据、单位及测试条件
- [ ] 无私自增加结构、工艺、算法或编造对比例

## 保护布局
- [ ] 检索结果注明数据库、日期、来源
- [ ] 独立权利要求包括必要技术特征
- [ ] 每条从属权利要求的新增限制有依据
- [ ] 多项从属引用规则已人工检查
- [ ] 方法/系统/工艺主题的单一性已评估

## 说明书
- [ ] 名称与请求书一致
- [ ] 5个常规章节齐全（或有合法例外说明）
- [ ] 有益效果和具体技术手段对应
- [ ] 本领域人员能依据实施例实际实施
- [ ] 原始参数和测试结果相互一致

## 摘要和附图
- [ ] 摘要含标点不超过300字
- [ ] 摘要以技术方案为主，无宣传语
- [ ] 附图逐图编号且标记一致
- [ ] 图形在缩小打印后仍清晰
- [ ] 必要时指定摘要附图

## Word/电子交付
- [ ] A4、留白、字体行距依现行官方规范复核
- [ ] 主体文件分开输出，页码自成体系
- [ ] 图、公式、中文标点未发生乱码与遮挡
- [ ] 每一页完成渲染检查
- [ ] 最终稿无TODO、隐藏批注、修订痕迹及非必要元数据
- [ ] 按申请渠道使用当前有效请求书与电子规范
