# 01 法规要求与内部格式分层

## 规范层级（冲突时的裁决顺序）

1. 《中华人民共和国专利法》（现行有效文本）。
2. 《中华人民共和国专利法实施细则》（2023年修订，自2024年1月20日起施行）。
3. 《专利审查指南》（2023版及2025年局令第84号修改，自2026年1月1日起施行）。
4. 国家知识产权局的当前申请表格、电子提交系统技术要求以及适用公告。
5. 单位/代理所内部模板：可以要求更一致的视觉样式，但不能覆盖上面规则。

**重要**：本文件为2026-10-16时点的检索整理；法律条文、电子文件格式、字号与版心要求可能更新。最终申请前应再次核验。[官方网址见 11]

## A. 法定/指南层的核心规则

| 项目 | 规则（提要） | 对应操作 |
|---|---|---|
| 主体文件 | 发明专利申请一般包含请求书、说明书摘要（及指定的摘要附图）、权利要求书、说明书、说明书附图（如有）；具体按实际申请情形 | 各部分分别完成并核查提交 |
| 说明书 | 名称须与请求书一致；通常按技术领域、背景技术、发明内容、附图说明、具体实施方式组织 | 保持标题和内部内容的一致性 |
| 权利要求 | 一项独立权利要求应有解决问题的必要技术特征；从属增加限定特征 | 先保护最小可实施方案，再建立回退 |
| 引用关系 | 从属只能引用在前的权利要求；多项从属使用择一引用，且不能作为另一多项从属基础 | 用校核脚本+人工检查 |
| 术语 | 权利要求与说明书术语一致；权利要求允许必要的化学/数学式，不应插图 | 维护统一词汇表 |
| 摘要 | 概述名称、技术领域、问题、技术方案、用途；以方案为主；摘要文字包括标点不得超过300字 | 测字数，避免宣传语 |
| 附图编号 | `图1、图2……`；同一部件全文标号一致；文字和图示要相互出现 | 逐图检查交叉引用 |
| 发明名称 | 一般不超过25字，必要时不得超过60字 | 不把25字写成无例外硬限制 |
| 用纸规格 | A4（210×297 mm）竖向为常规 | 单独文件、独立页码 |
| 页边留白 | 上侧及左侧25 mm，右侧15 mm，底部从页码下沿至纸张边缘15 mm | 注意底边是“从页码下沿”而非简单 Word margin 等价 |
| 字体与行距 | 官方要求对字形、字高、行距另有规定；应核对现行文本和电子提交渠道 | 内部12pt宋体/1.5倍行距仅为起点 |
| 附图线型 | 清晰、均匀、可辨；通常黑色线条，必要时可用彩图；照片通常不适宜、特定情形可例外 | 不作“禁止所有彩图照片”的错误表述 |
| 发明人信息 | 发明人须为自然人并真实，2026版要求请求书填写所有发明人身份信息 | 由授权人员核验，不写虚假发明人 |

## B. 与正式规范不同的“内部编辑推荐值”

| Word 选项 | 内部推荐起点 | 性质 |
|---|---|---|
| 纸张 | A4，纵向 | 遵循申请规格的便捷设置 |
| 页面边距 | 上25/左25/右15/下15 mm；页码下沿距离须另调 | 版面起点，不保证底部形式合规 |
| 正文中文字体 | 宋体，12 pt | 内部默认，非逐字规范引用 |
| 正文对齐 | 两端对齐 | 可读性建议 |
| 正文行距 | 1.5倍 | 内部编辑建议，需渲染复核 |
| 首行缩进 | 按官方样式或代理所模板，建议全文统一 | **非强制统一数值** |
| 段前段后 | 正文为0或按统一模板 | 内部风格 |
| 标题样式 | 主标题/章节标题分级、使用同一字号方案 | 内部风格 |
| 页码 | 各正式组成文件独立顺序编号 | 便于形式审查 |
| 文件标签 | `工作草案_v01`、`发明人确认_v02`、`代理审查_v03` | 版本管理建议 |

## C. 特别容易写错的规则

- “技术交底书”是撰写输入，不是必须提交的申请主体文件。
- 附图不是越多越好；缺少必要的结构/流程图可能导致难以理解，但用论文装饰性示意图并不自动合规。
- “摘要不超过300字”计入标点符号；检查脚本需人工复核 Word 实际显示文字、特殊符号及计数方式。
- “必要时发明名称放宽至60字”是上限例外，仍以准确简明为先。
- Word 的`下边距=1.5cm`不等同于“页码下沿距页边15mm”。
- 实施例中具体尺寸只是优选例，不能自动证明各种宽泛的数值范围可行；权利要求上位概括需要原始材料和技术推理支持。
- 发明专利可涉及方法主题；实用新型主题不同，不应把两者的独立权利要求混用。

## D. 核验方法

最终提交前依次比对：最新官方请求书 → 现行指南（包括后续修订）→ 申请系统报错及电子技术要求 → 渲染稿视觉检查 → 代理人确认。发生冲突时记载条文位置和版本日期，不能用习惯替代法规。
