# 07 Word 格式与正式交付流程

## 文件组织（推荐）

```text
专利项目_版本号/
├── 01_说明书摘要.docx
├── 02_权利要求书.docx
├── 03_说明书.docx
├── 04_说明书附图.docx       # 有附图时
├── 05_申请信息与请求书填写清单.md
├── 06_发明人待确认问题.md
└── 07_校核报告.md
```

请求书使用国家知识产权局当前渠道要求的官方表格或电子填写方式；本 Skill 不假冒官方请求书。申请文件的法定排序和系统上传槽位应以官方规则为准；本地文件名只为管理方便。

## 页面参数

A4 210×297 mm；顶留白25 mm、左留白25 mm、右留白15 mm、底部从页码下沿至纸张边缘15 mm（如涉及页码，需结合页脚位置实际验证）；正文行距与字高依据现行指南。Word 空白模板默认选 12 pt 宋体与1.5倍行距，仅作编辑起始值。

通过段落/字体/页面样式统一控制，不要靠连续空格、多个空行或手动换行进行“视觉凑齐”。公式和符号应使用可正确显示的字体，并核查下标、上标、希腊字母、微米符号、乘号和范围号。

## 不同文件的细节

**权利要求书**：按阿拉伯数字依次列出，各项边界清楚；确保“1.”不是 Word 自动编号造成的引用误差。避免一条权利要求拆成不相连的多个段落而丢失编号。

**说明书**：名称前后一致；技术领域、背景技术、发明内容、附图说明、具体实施方式标题完整；长篇内容可用标题样式便于核查，但输出呈现仍依规定排版。除非性质需要，不应颠倒法定章节顺序。

**摘要**：通常独立成文件，摘要正文在规定字数内；有图时摘要附图应与指定的说明书附图一致。

**附图**：每幅图清晰，图号统一。工作 Word 可以插入高质量原图；电子提交前依当期渠道处理为可接受的格式与布局。

## DOCX QA（不可跳过）

1. 用 `python-docx` 或 Word 完成编辑并保存源文件。
2. 用支持图像渲染的工具逐页导出 PNG/PDF，核查每页：汉字显示、图片不糊、标号/箭头、公式、页眉页码、边距、目录/章节、断页/漏页。
3. 手动检查全文检索：【待确认】、TODO、批注、高亮、修订、测试备注、来源文件名、个人联系方式等。
4. 对照“术语表”“图号字典”“权利要求支持矩阵”进行全文交叉审查。
5. 若使用 Word 正式修订模式，定稿后正确处理修订痕迹和批注，另存新文件；不要随意覆盖原始历史版本。
6. 对正式交付与内部审查稿设置不同文件名/目录并明确标识。

## 审查单最小交付清单

- [ ] 法定主体内容齐全（按申请类别）
- [ ] 摘要字数核验通过
- [ ] 权利要求引用合法，术语一致
- [ ] 说明书完全支持权利要求
- [ ] 图号、标记和文中引用一致
- [ ] 数据、参数都有依据，不存在虚构项
- [ ] 已公开情况、发明人及权属由有权人员确认
- [ ] 每页渲染并目视审查，无重叠、断行、中文乱码
- [ ] 提交前核对最新国家知识产权局要求

## 版本交付说明样式

“文件版本：【vX】；新增/调整：【范围】；内容证据来源：【列出材料编号】；尚需发明人确认：【问题】；已核查项目：【清单】；尚未核查的法律风险：【清单】。”
