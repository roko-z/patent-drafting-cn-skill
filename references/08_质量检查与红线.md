# 08 质量门槛、错例与修订优先级

## 质量打分（内部项目管理建议，非官方授权标准）

| 维度 | 重点 | 建议权重 |
|---|---|---:|
| 技术真实性 | 有来源、没有捏造/冲突未解决 | 25% |
| 公开充分 | 按说明书可以实施而不需猜核心步骤 | 25% |
| 权利要求质量 | 必要特征完整、范围合理、回退充分 | 20% |
| 新颖性与差异分析 | 检索可追溯、D1映射完整 | 15% |
| 术语与附图一致性 | 图号/编号/单位/方向一致 | 10% |
| 排版与交付 | 页面清楚、文件独立、元数据干净 | 5% |

任何 `BLOCKER` 均禁止“可直接提交”的结论；总分只用于改稿排期，**不是专利可授权概率**。

## 阻断项（BLOCKER）

- 核心工艺/步骤/连接关系未经确认，却以确定语气写进独立权利要求。
- 任何实验数据被推算、凑数或伪造，无法解释测量条件。
- 用户的发明已公开时间不明，尚未评估申请影响却宣称“保证新颖”。
- 文中技术方案无法独立实施，存在悬空的“通过某智能算法自动实现”等句式。
- 发明人身份、权属不实或者把 AI/集体填作发明人。

## 重大项（MAJOR）

- 独立项缺必要特征，从属项无前项引用依据。
- 从属多项引用不满足法定引用关系。
- 说明书某关键特征不存在/与权利要求矛盾。
- 附图标号冲突、图示构件方向矛盾。
- 保护范围跨越缺乏依据的材料、尺寸或方法类别。
- 背景将发明人的新技术说成已知技术。
- 摘要超过当前字符要求或无主要技术方案。

## 轻微项（MINOR）

- 名称不统一、符号字体/上下标不一致。
- 中文标点和数字空格混乱。
- 漏用“所述”、编号样式不统一、文件名含过期版本号。
- 段前段后、分页和页码不协调。

## 六轮复核流程

1. **事实核对**：材料证据 → 每一技术主张/量化表述。
2. **逻辑核对**：问题 → 必要特征 → 作用 → 效果。
3. **权利要求核对**：独立项与从属项逐条去掉模糊语。
4. **支持关系核对**：权利要求 → 说明书 → 附图 → 实施例。
5. **现有技术核对**：差异特征、表述风险、公开状态。
6. **排版核对**：渲染 PDF/PNG 并逐页检查。
