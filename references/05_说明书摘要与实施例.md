# 05 说明书、实施例、摘要：从草稿到可实施文本

## 说明书五段式（正式输出的常见顺序）

### 技术领域

一段即可，说清所属技术领域和具体方向，不写效果排名、不引入未经定义的新颖特征。占位句式：“本发明涉及【技术领域】，尤其涉及一种【技术客体】及其【方法/系统】。”

### 背景技术

写明最接近的已有方案及不足，避免“大背景堆砌”。建议三层：背景及现有技术 → 其如何运行 → **具体仍未解决的技术问题**。合理引用已检索文件，不要把自己的技术方案提前写成现有技术，也不要随便断言所有现有技术“无法实现”。

### 发明内容

分为三小组：

1. **发明目的/技术问题**：明确当前方案要解决的具体、可检验困难。
2. **技术方案**：与独立权利要求对应的必要技术结构/步骤完整、可实施；后接优选实施方式，术语一致。
3. **有益效果**：每条按`技术特征 → 作用机理 → 可验证效果`表述，真实量化结果注明测量条件，缺失数据不得编造。不要使用“国内首创”“绝对无误差”等宣传语。

### 附图说明

逐图写：“图1为本发明【图示内容】的示意图。”若有附图标号清单，再集中写“图中：1—【名称】；2—【名称】”。附图说明写“是什么图”，结构与使用方式详细解释放到具体实施方式。

### 具体实施方式

按从整体到局部、从结构到工作、从优选到对比例展开。

**装置/系统实施例模板**：

1. 先说明图1的总结构、每一组成部分。
2. 按信号流/能量流/物料流或物理位置展开各部件的连接关系。
3. 明确正常工作时的输入、触发、操作、中间结果和输出。
4. 解释关键部件的物理/计算作用，不要仅复述“提高性能”。
5. 加入参数、可选配置、故障/边界情形（如已证实）。
6. 以真实测试/对比例说明技术效果（若材料可用）。

**方法/工艺实施例模板**：

- `步骤S1`：输入、前置状态、执行主体、操作、输出或中间产物。
- `步骤S2`：所依赖的前一步结果、工艺/算法手段及参数。
- `步骤S3`：判断条件、分支及输出。
- 若有循环/时序处理，定义何时开始与结束。
- 对可选步骤标为“在另一实施方式中……”，不要把缺失的步骤用空泛功能口号填满。

**材料实施例模板**：原料与纯度 → 配比或名义浓度 → 设备环境 → 工艺步骤与温度/时间 → 产物识别/检测方法 → 性能测量与对照；保护范围需要有边界支持。

## 适度的上位概括

不能把一个实验点自然推成“任何条件均成立”。区分：

- `实施例具体值`：真实测量或实际加工值。
- `可选范围`：有实验或技术原理支撑的可实施范围。
- `希望保护范围`：尚需研究验证，不能直接当事实落到权利要求。

公开多个真正替代手段可以提高回退能力，但未经验证的替换不可自作主张。对于某些领域可通过公知常识支持合理概括，但须留有论证依据。

## 说明书摘要

先完成主权利要求再写摘要，不把摘要当广告。推荐四部分：名称/领域（简短）、技术问题、关键技术方案（主体）、用途/客观有益效果。摘要含标点不超过300个字。摘要中不宜塞背景长史、权利要求编号、主观广告词。若必须出现附图标记，按指南规范处理。

**摘要通用占位范式**：

> 本发明公开了一种【名称】，属于【领域】。其包括【关键组件或步骤】，其中【最重要的关系或操作】用于【可核查的技术目的】。通过【必要方案】，实现【客观技术结果】，可用于【用途】。

这只是一种语言框架，不能代替具体技术方案。

## 论证技术效果的证据等级

- A：同条件对照及重复实验原始数据。
- B：单组原始实验并有完整条件描述。
- C：来源明确的理论计算/仿真并有模型及边界。
- D：合理但尚未经实验验证的机理推断。
- E：仅目标愿景/营销措辞，不能作既定技术效果。

优先使用A/B证据。C必须标注“仿真/计算”，D必须写“可能/推测”等限缩表达并审慎评估，E不应写入确定结论。

## 完整性检查

说明书至少要让审查者不用猜你想保护什么、怎么做、为什么能达到技术目的。每一个独立权利要求都能找到一个完整支持链；每一个从属特征都能找到可实施说明；每一个附图标记都有文字解释；每一实验数字都有单位、条件、来源。
