# 中国发明专利从零到一撰写 Skill

**版本**：1.0.0（2026-10-16）　**覆盖范围**：中国发明专利撰写、审查、排版、项目材料转专利。

## 使用方式

1. 在支持 Agent Skills 的环境中，解压文件夹，按平台说明安装/引用 `SKILL.md`；也可以直接将 `SKILL.md` 与关联 `references/` 目录提供给助手使用。
2. 从一个具体指令开始，例如：“根据我提供的交底书，按照本 Skill 的 G0—G3 先做创新点与权利要求布局，不要编造缺失数据。”
3. 技术资料尚不完整时，优先填写 `templates/技术交底书_可填写.md` 或 `templates/docx/技术交底书_空白模板.docx`。
4. 正式申请文件的 Word 起点见 `templates/docx/`，运行 `scripts/patent_lint.py` 做第一轮机械检查，再进行人工和专业审查。

## 目录

- `SKILL.md`：执行入口、九关工作流、优先级与质量门槛。
- `references/`：法律格式、交底、检索、权利要求、说明书、附图、排版、审查、专项与提示词。
- `templates/`：通用资料台账、特征矩阵、审查清单、空白 DOCX。
- `scripts/patent_lint.py`：DOCX 常见问题检查，输出 Markdown 报告。
- `scripts/build_blank_templates.py`：生成空白 DOCX 的源码，可修改排版设置后重建。
- `examples/`：虚构占位符的通用写法（无真实项目细节）。

## 重要声明

本项目包含学习和撰写辅助材料，**不是国家知识产权局官方格式包，也不构成具体案件法律意见**。请使用最新官方请求书、平台格式和审查指南；真实授权策略由发明人和代理专业人士复核。

**脱敏策略**：不包含用户上传的原始文档、技术领域、发明名称、具体材料、参数、曲线、原始图稿、人员或机构信息。引用范文只保留通用结构。
